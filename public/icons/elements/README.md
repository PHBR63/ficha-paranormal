As imagens preservam a arte de origem. O componente usa enquadramento circular para integrar a textura ao ícone. Não são símbolos criados por IA. Os ícones de ações e recursos são Phosphor/Lucide, de suas respectivas bibliotecas; não são apresentados como desenhos oficiais do RPG.

O PDF original não é incluído nem distribuído. Este diretório contém somente os cinco detalhes utilizados na interface do projeto de fã.
